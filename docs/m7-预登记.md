## 假设与检验族(Holm,$\alpha = 0.05$,2 个 $p$ 值)

| 编号 | 假设 | 终点 | 效应量与检验 |
|---|---|---|---|
| H1 | FT3 高于 FT2 | 单步成功率,test-v2 全部 300 题 | $\hat\Delta_1 = \hat p_{\mathrm{FT3}} - \hat p_{\mathrm{FT2}}$;配对 bootstrap 95% 区间(10,000 次,种子 42)与聚类 bootstrap 区间(草拟题按模板族成簇,每道手写题自成一簇,`eval.metrics.cluster_keys`);配对精确 McNemar 的双侧 $p$ |
| H3 | FT3 对 B0(胜出底座)在 ACEBench 上非劣,余量 $\delta = 0.02$ | ACEBench 汇总 $\bar a$:各(语言, 类别)层准确率的算术平均。一层是一种语言(zh 或 en)与一个 ACEBench 数据类别的组合,对应原始回答里的一个评分文件 `<语言>/score/data_<类别>_score.json`(`eval.acebench`);normal 与 special 是类别的两个分组,不是类别本身:`results/acebench-m6.json` 的 `groups` 中 normal 组 12 个类别(如 `normal_atom_bool`)、special 组 3 个(如 `special_irrelevant`)。M6 因此为 2 × 15 = 30 层、每系统 1,940 个答案(normal 1,640、special 300,`docs/m6-预登记.md`);M7 的层数与答案数〔待填:取自 `results/acebench-m7.json`〕 | $\hat\Delta_3 = \bar a_{\mathrm{FT3}} - \bar a_{\mathrm{B0}}$;分层配对 bootstrap:每次重抽在每层内逐答案有放回抽取同样多的答案(两系统同一批),层准确率之差取各层平均,得 $\hat\Delta_3^{*}$;$p_{\mathrm{NI}}$ 为 10,000 次重抽中 $\hat\Delta_3^{*} \le -\delta$ 的比例,种子 42(`eval.metrics.stratified_noninferiority_p`,与 M6 相同) |

- 两个 $p$ 值一起做 Holm 校正:H1 用 McNemar 的 $p$,H3 用 $p_{\mathrm{NI}}$;顺序同 `results/test-config-m7.json` 的 `comparisons` 前两行(`ft3-vs-ft2`、`ft3-vs-b0-acebench`)。区间不做多重校正。H3 的 bootstrap 在打开时与其他比较一起计算,打开之前不算。
- `ft3r-vs-b2`、`ft3r-vs-ft3` 两行只作描述:差、配对与聚类区间、不一致计数;`descriptive: true`,运行器不为它们算 $p$,不进检验族。
- 编号沿用计划 WP-M,本轮没有 H2。FT3+R3 的目标由 P1、P2 的点估计判定(下节);P1、P2 是判据,不是假设检验,不进 Holm 族。
- H1 比较的是 M7 的整体改动(换底座、思考训练、扩充数据、自回放)对 M6 的 FT2,不归因于其中某一项。底座对比的试训与两个消融(FT2 的数据、第 274 步,`docs/m7-进度.md`「C0 的思考消融」与「C2 的不思考消融」)可作部分分解,只作描述。
- 终点照计划为全部 300 题;手写子集与草拟子集上的差只作描述。

## 成功判据(事先写死)

- **P1 达成**:FT3+R3 单步成功数 $k_1 \ge 270$(共 300 题),且 $c_{\mathrm{FT3+R3}} \le 0.5\,c_{\mathrm{B2}}$。
  - $c_s = 100\,L_s / 300$(元/百题)。$L_s$ 是系统 $s$ 的单步云端回合按列表价折算的金额,即 `results/test-m7-resources.json` 的 `systems.<s>.cost.single_step.list_rmb`:FT3+R3 只计转交的题;B2 计全部 300 题,命中缓存的回合同样按列表价计入(`prices.json` 不登记 flash 的缓存命中价,与 M3–M6 的列表价口径相同)。
  - 这与 G3 的成本上限同一口径:`scripts/route_curve.py` 的上限是全部交给 B2 的列表价成本的一半(`CAP_SHARE = 0.5`)。
  - 不用实付金额:会话中 FT3+R3 先于 B2 运行,FT3+R3 已付费转交的题由 B2 再答时命中缓存,实付取决于运行顺序;列表价不受影响。
- **P2 达成**:FT3+R3 端到端成功数 $k_2 \ge 135$(共 150 个任务,逐步路由)。
- **区间**:P1、P2 的成功率都报告 Wilson 95% 区间 $\left[\hat p + \frac{z^2}{2n} \pm z\sqrt{\frac{\hat p(1-\hat p)}{n} + \frac{z^2}{4n^2}}\right] \Big/ \left(1 + \frac{z^2}{n}\right)$,其中 $\hat p = k/n$,$z = \Phi^{-1}(0.975) \approx 1.96$。按所有者的决定,判据只看点估计,区间不构成判据。按上式($z = 1.959964$)算得:$k_1 = 270$ 时区间为 [86.1%, 92.9%],$k_2 = 135$ 时为 [84.2%, 93.8%];点估计恰好达标时,区间仍含低于 90% 的值。
- **H1 达成**:H1 校正后 $p < 0.05$ 且 $\hat\Delta_1 > 0$。
- **H3 达成**:H3 校正后 $p < 0.05$。
- **措辞**:P1、P2 达成时写「FT3+R3 达到目标」,不写成本地模型自身的能力;FT3 单独的成绩与手写子集的成绩并列报告(计划「风险与对策」)。

## 描述性结果(不做检验)

- **单步,各系统**(FT3、FT3+R3、FT2、B2):按题型(call、clarify、next_step、no_call、parallel、recover)、语言、草拟与手写子集的成功率;误差分类计数(`error_class`)。FT3 单独的成绩与 FT3+R3 并列。
- **两行描述性比较**:`ft3r-vs-ft3`(路由带来的差)与 `ft3r-vs-b2`:差、配对与聚类区间、不一致计数。H1 的差在手写与草拟两个子集上分别报告。
- **B2 单步作参照**:草拟题 192 道的金标准就是 flash 自己的回答,B2 的请求与生成轨迹时相同,回答由响应缓存原样返回,草拟题上的 B2 分数不说明能力;只有手写题 108 道上的分数反映 flash 的能力。另报 B2 各思考模式的回合数。开发侧同样如此:B2 在 dev-v2 上 126/126、在 dev-v2-ext 上 23/23,全部来自缓存,花费 0 元(`docs/m7-进度.md`「B2 的开发侧运行」)。
- **路由**:FT3+R3 的转交数与比例,其中草拟题与手写题各多少;硬触发按类型计数,预算触发与参数触发计数;同转交比例的随机路由的期望成功率 $(1 - s)\,\bar y_{\mathrm{FT3}} + s\,\bar y_{\mathrm{B2}}$($s$ 为转交比例,$\bar y$ 为同一批题上的平均成功率);一致性:本地作答的题中输出与 FT3 单步记录逐字节相同的题数,转交的题中与 B2 记录相同的题数。
- **思考**:FT3 与 FT3+R3 每步思考长度的中位数与 p95、强制收尾数,单步与端到端分开报告。
- **端到端**:四个系统在 150 个任务上的成功率与每任务步数。FT3+R3 是 P2 的终点,FT3 并列;FT2 与 B2 只作描述,B2 是「全交云端」在 v2 端到端上的参照,FT2 可与它在 v1 端到端上的 43/60(M6)对照。FT3+R3 有转交的任务数、本地与云端的调用数和步数;各系统超出训练长度的步数(运行器不统计,打开后从转录记录补算,计划 §2「端到端预算」)。

- **时延与资源**:时延 p50 与 p95(本地每次调用;FT3+R3 的本地、转交、转交且付费三组;端到端每步),每台服务器的显存增量与功率。目标函数不计时延(所有者的决定),只作量级参考。
- **ACEBench**:normal / special 两组的准确率、格式计数(口径同 M6)、FT3 对 B0 的各层差、思考长度。
- **v1 与 v2 的难度对照**:FT2 在 v1(M6:单步 74.3%、端到端 71.7%)与 v2 上的成绩。
