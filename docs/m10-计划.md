# M10 计划:科研助理的对话框网页

**状态:所有者 2026-11-12 批准。**过程记在 docs/m10-进度.md。本计划不打开任何测试集,不训练,不改动被评测的系统,云端 API 花费为 0。

## Context

- **起因**:M9 之后,助手要在 PowerShell 里用 `scripts/ask.py --interactive` 对话。所有者要求把它做成对话框的形式。
- **所有者的选择**:
  1. 本地网页:在浏览器里打开,只用 Python 标准库加一个页面,不装新依赖;
  2. 每条消息独立,与评测一致:页面显示历史,模型每次只看当前这条;它追问时,下一条消息作为回答接上(至多 2 次);
  3. 除问答外显示四项:每步进度、笔记库面板、可点击的论文编号、每步的思考过程(默认折叠);
  4. 只在本机访问:只监听 127.0.0.1。
- **目标**:`ask.py --web` 启动后在浏览器里对话;运行的仍是未经改动的 M7 final,每轮落盘的文件、身份核对与单实例锁都与 `--interactive` 相同。
- **边界**:docs/m9-计划.md「不改动的部分」所列文件保持字节不变;只做新增模块、只观察的包装、默认值保持原行为的新参数。显卡只在最后的实测使用约 15 分钟。

## 做法

### 1. 结构化进度事件(`src/research_agent/live/session.py`)
- `run_live_turn`、`ProgressModel`、`progress_tools` 各加 `events=None`。不传时行为与输出逐字不变;传入时,用与进度行同一组取值另发一个字典,不多调用一次计时或限速计数。
- 事件种类:
  - `step_start`;
  - `step`:步号、尝试号、用时、投票(样本数、胜出票数、代表回答来自哪个候选、失败的候选)、思考(token 数、是否被强制收尾)、代表回答那一次生成的思考文本、触发的规则、调用(编号、工具名、参数)、回答长度;
  - `step_error`、`tool_start`、`tool`(工具名、摘要、错误码、论文编号、用时、限速等待)、`tool_error`。
- 事件接收方出错只停掉事件本身,不影响这一轮。
- 新增 `Conversation`:追问状态、至多 2 次接续、空回答保留原请求、放弃待回答的追问。`--interactive` 改用它,打印的每一句不变;网页用同一个类,两者语义一致。

### 2. `scripts/ask.py --web`
- 新增 `--web`(与其他方式互斥)、`--web-port`(默认 8765,不得与 llama-server 的端口相同)、`--no-browser`。
- 网页端口在组装系统之前先绑定:端口被占时立即以退出码 2 停下,不先加载模型。
- 其余沿用 `run()`:运行目录、`session.json`(kind 为 `web`)、身份核对、笔记库、实时工具、单实例锁、Ctrl+C(退出码 130)。
- 每一轮在主线程上运行,HTTP 服务在后台线程。

### 3. 网页服务(`src/research_agent/live/web.py`)
- 标准库 `ThreadingHTTPServer`,只绑定 127.0.0.1;在 Windows 上关闭地址复用并独占绑定,端口被占时不会误绑定成功。
- 访问控制:
  - 控制台打印并在浏览器打开带一次性令牌的链接,打开后换成 HttpOnly、SameSite=Strict 的 cookie;
  - 每个请求的 Host 必须恰为 `127.0.0.1:<端口>`;
  - POST 另须同源的 Origin、同源的 Sec-Fetch-Site、JSON 类型,请求体不超过 64 KiB;
  - 响应带 CSP(只许本站脚本与样式)、禁止被嵌入框架、nosniff、no-store,不发跨域许可头;
  - 不打印请求日志。
- 接口:

  | 路由 | 作用 |
  |---|---|
  | `GET /` | 页面 |
  | `GET /static/…` | 脚本与样式 |
  | `GET /api/state` | 当前全部状态 |
  | `GET /api/events` | 实时推送(SSE),重连时补发或给快照 |
  | `POST /api/ask` | 提问;一次只跑一轮,忙时 409 |
  | `POST /api/new` | 放弃待回答的追问 |
  | `POST /api/quit` | 结束运行;一轮进行中则等它结束 |
  | `GET /api/notes` | 笔记列表 |
  | `GET /api/notes/<编号>` | 一条笔记 |

- 状态由服务端汇总:每次往返(请求、各步、各工具、结果)作为整体对象推送,页面只负责显示;重新载入或关掉再打开都能恢复。
- 单行消息:训练与评测只用过单行用户消息,提交的文字合成一行再发,页面显示实际发出的文本。
- 笔记编号先按 `^\d{4}\.\d{4,5}-[1-9]\d*$` 全匹配,再确认路径在笔记库目录内,才读文件。

### 4. 安全的文本渲染(`src/research_agent/live/render.py`)
- 回答与笔记在服务端转成 HTML:先转义,再处理一小组 Markdown(标题、嵌套列表、粗体、行内代码、代码块、段落),一遍完成;不接受模型文字里的链接、图片或原始 HTML。
- 新式 arXiv 编号与 arxiv.org 的论文链接改为指向 `https://arxiv.org/abs/<编号>` 的链接,判定用评测计算引用编号的同一个正则。
- 思考文本作纯文本显示。

### 5. 页面(`src/research_agent/live/page/`)
- 左边对话,右边笔记库面板(列表与查看,写了新笔记后刷新);顶部显示冻结记录的哈希、构建号与服务器状态。
- 对话:
  - 气泡下显示实际发出的文本;
  - 进行中逐步显示每步的票数、思考 token、调用与用时,工具结果挂在步下;
  - 每步可展开思考,注明来自哪个候选、是否被强制收尾、规则是否改写了回答;
  - 结束后显示回答、状态、用时、写出的笔记,以及不在本轮工具输出中的引用编号。
- 输入:
  - Enter 发送,输入法确认词语时不发送;
  - 一轮进行中禁用输入,并说明不能中途取消;
  - 追问时提示下一条消息是回答(n/2),并给「新问题」按钮;
  - 「结束运行」按钮。
- 只用 `textContent` 写文字;唯一一处 `innerHTML` 只插入服务端渲染的 HTML;不加载外部资源。

### 6. 文档与导出
- README「使用」加 `--web` 的命令与说明:链接在控制台;端口 8765;一次一轮、不能取消;关掉页面不结束运行;用「结束运行」或 Ctrl+C 结束;控制台窗口被点选时输出会暂停。「状态」加 M10 一条。
- 导出工具:本计划加入公开的计划清单,进度记录的链接改写为私有说明。

| 风险 | 对策 |

| 加事件改变了请求或回合 | 测试比对开、关事件时的请求字节与回合对象 |

## 实施记录(2026-11-13 追加;上文是批准稿,未改动)

实现与上文不同、或上文没有写到的地方:

- 第 1 节「空回答保留原请求」是笔误。M9 的 `--interactive` 在追问之后收到空回答时放弃该请求,而本计划要求它打印的每一句不变,所以 `Conversation` 沿用这一行为:空回答放弃该请求,网页与控制台相同。
- 入口令牌在本次运行期间一直有效,不是一次性的:同一条链接可以再次打开页面(例如换一个浏览器窗口,或 cookie 被清除之后)。令牌只出现在本机的控制台与浏览器中,运行目录里的文件不记录它。
- `--web-port` 另外不得为 80:浏览器访问 80 端口时发送的 Host 不带端口号,与逐字核对的 Host 冲突。`--web-port 0` 表示任选一个空闲端口。
- 控制台当作命令或失误的输入(第一个词以 `/` 开头,或单独的 exit、quit,不分大小写),网页拒绝发送,与控制台从不把它们发给模型一致。
- 运行在一轮进行中结束时(Ctrl+C 或出错),页面把这一轮和其中未完成的步骤与工具调用标为「已中断」,不再显示为进行中。这一项由显卡实测发现。
